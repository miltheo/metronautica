Metronautica

Metronautica: Navigate wearable triaxial accelerometer signals into transparent metrology and reports.

Parse recordings, assess signal quality, characterise measurement response and extract acceleration features. Developed for a research article under submission; analyses and recording samples are in WAM.

Processing workflow

Stages can run independently; optional calibration returns to assessment with refreshed QC. Click a diagram box for details.

Installation

Install dependencies in R:

install.packages(c("tibble", "dplyr", "data.table", "digest", "jsonlite",
                   "signal", "ggplot2", "ggrepel", "scales"))

Download the repository, then install its directory:

install.packages("path/to/metronautica", repos = NULL, type = "source")

Alternatively, run R CMD INSTALL . from the repository root. Optional packages support selected decoders and features.

Quick start

library(metronautica)
example("getting-started", package = "metronautica")

For a native recording:

accel <- parse_raw_auto("path/to/recording.agsd", return = "bundle", qc = TRUE)
accel_meta(accel)$processing$qc
# Defaults: ENMO and MAD.
# Other features: see reference.
features <- compute_accel_summaries(accel, measures = c("ENMO", "MAD"), epoch_s = 5)
head(features$data_wide)

Static and dynamic examples include plots from separately distributed samples. Other package use requires no WAM downloads.

Acceleration tibble

Four columns: time (POSIXct, UTC), ax_g, ay_g, az_g (numeric, g). Attached meta stores acquisition settings, provenance and QC; accel_meta() reads it. For decoded data, use as_accel_tbl() and attach_qc(). Data contract.

Static characterisation

Select a stationary interval. static_metrology_from_tbl() returns signed 1-g VM offset bias, drift rate, static noise floor, Allan deviation and plots. Static example.

Dynamic characterisation

Specify a reference, excitation schedule and measurement range. clip_dynamic_stages() selects stages; dynamic_metrology_report() returns VM response slope, signed VM bias, VM integral non-linearity, composite error and plots. Dynamic example.

Feature extraction and visual comparison

compute_accel_summaries() returns epoch features and settings; accel_metric_*() functions calculate individual features. Use plot_accel_clip() for acceleration, plot_processed_metric() for features and accel_metric_agcounts() for activity counts. Feature comparison and settings.

Metrology and feature reports

Retain units, reference, tested range and processing settings with the outcomes. Static reports return summary/meta; dynamic reports return stages/overall/meta; feature results return data_long/data_wide/settings. Outcome definitions.

Optional calibration

Fit and apply a VM mapping only when warranted. Independently validate its benefit, refresh diagnostics with attach_qc() and repeat the selected assessments. Calibration example.

Help and citation
