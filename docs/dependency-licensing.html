The signal 1.8-1 package declares GPL-2 in its metadata. The inspected butter, filtfilt, filter, sftrans, bilinear and poly source files explicitly permit version 2 or any later version, providing a GPL-3 option for the filtering path used here. This finding does not relicense unrelated files in that dependency.

Activity counts are implemented directly in R/m_agcounts.R; neither the R agcounts package nor the Python reference is a runtime/optional dependency. The published numerical coefficients are acknowledged from ActiGraph/agcounts (GPL-3.0), pinned commit 3137c9b9a26539ae2d9645d396586fe15faece59. The original R implementation is distributed under this package's GPL-3 licence. External comparison software remains separately licensed.
