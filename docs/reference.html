Metronautica: Navigate wearable triaxial accelerometer signals into transparent metrology and reports.

Description

Native wearable triaxial accelerometer parsing, signal diagnostics, static and dynamic characterisation, feature extraction and reporting.

Details

Use the linked guides for workflows and this reference for function behaviour. Filtering and calibration are explicit choices. The package returns recording-level outcomes; WAM supplies cohort inference and inter-device equivalence analyses.

Repositories

Developed for the wearable-accelerometer metrology research article under submission. Package source: https://github.com/miltheo/metronautica. Associated analyses, observations and native-recording catalogue: https://github.com/miltheo/wam.

Guides

Getting Started provides recording, characterisation, feature and calibration workflows; Function map connects stages to source files; Feature comparison shows the shared-trial example. The offline example below needs no external recordings or optional packages; parsing attaches primary-five diagnostics.

See Also

metronautica-tibble (the sample-level data contract), measurement-definitions

Examples

library(metronautica)
# Load the installed recording.
path <- system.file("extdata", "example_motion.csv",
    package = "metronautica", mustWork = TRUE)
x <- parse_raw_auto(path)
# Defaults: ENMO and MAD.
# Select features explicitly.
features <- compute_accel_summaries(x, measures = c("ENMO", "MAD"),
    epoch_s = 5, quiet = TRUE)
# Inspect values and units.
head(features$data_wide)
features$settings$metric_units

Compute ActiGraph-compatible or modified activity counts

Description

Standalone published-filter activity counts, with optional custom band-pass cutoffs and explicit gap/boundary handling.

Usage

accel_metric_agcounts(tbl, epoch_s = 1, fs_hz,
    lower_hz = NULL, upper_hz = NULL, filter_order = 4,
    lfe = FALSE, gap_policy = c("error", "zero", "carry_forward"),
    vm_round = TRUE, start_time = NULL, end_time = NULL,
    boundary = c("error", "pad"), pad_value = NULL,
    filter_guard_s = 60)

Arguments

tbl

Acceleration table or data/full bundle with POSIXct time and finite numeric ax_g, ay_g, az_g (g). Requires strict timestamp order on the nominal sampling grid; observed zero samples are retained.

epoch_s

Positive whole-second epoch duration. Accumulate axes before VM calculation. Discard incomplete trailing raw epochs before rate conversion; record discarded sample count.

fs_hz

Explicit nominal recording rate (Hz): 30, 40, 50, 60, 70, 80, 90, 100, 32, 64, 128 or 256. Gap-spanning timestamp estimates cannot substitute for acquisition settings.

lower_hz, upper_hz

Both NULL retain exact published coefficients, rather than substituting nominal cutoffs. Supplying both selects modified causal Butterworth filtering with -3-dB edges satisfying 0 < lower_hz < upper_hz < min(15, fs_hz/2). Internal processing remains 30 Hz.

filter_order

Custom Butterworth prototype order, integer 1–8 (default 4); ignored for the published filter. See Calculation stages in the counts guide for transfer order and gain matching.

lfe

Enable the published low-frequency-extension threshold rule (default FALSE), without changing filter coefficients. Quantisation rules are in the counts guide.

gap_policy

error (default) rejects missing interior sample positions; zero inserts zero acceleration; carry_forward repeats the last observed triaxial sample. Fill values are computational conventions, not measured missing acceleration. NA/Inf axes error rather than becoming gaps.

vm_round

TRUE rounds sqrt(Axis1 squared + Axis2 squared + Axis3 squared) to the nearest integer, matching the R comparator; FALSE retains unrounded VM. Summing one-second VM differs from accumulating axes before VM calculation.

start_time, end_time

Single POSIXct bounds, inclusive start/exclusive end; defaults: first sample and last sample plus one nominal interval. Epochs begin at resolved start_time without civil-clock rounding. Metadata distinguishes native start from first observation. Process continuous input before selecting epochs when filter history matters.

boundary

error (default) rejects bounds beyond coverage; pad permits explicitly requested end padding with required pad_value. Native-header bounds are never applied automatically; padding does not establish vendor compatibility.

pad_value

Three finite X/Y/Z accelerations (g) for boundary = "pad", used at both requested ends. Padding counts/locations are reported; no implicit constant-first-sample startup padding.

filter_guard_s

Non-negative flagging interval after imputation/initialisation (default 60 s). Centred-FIR power-of-two conversion also flags the second before imputation and the final processing second. Flags do not change counts. This context guard is not a validated settling time or uncertainty bound; lower custom cutoffs may need longer guards.

Details

Defaults use the published coefficient-defined filter. Custom cutoffs replace only that stage and produce modified counts, without inherited behavioural-threshold validation. Calculation stages and validation documents rate conversion, quantisation, precision, boundary effects and agreement results.

Value

Tibble: time, Axis1 (input Y), Axis2 (input X), Axis3 (input Z), Vector.Magnitude and value (same VM). Per-epoch input_samples, missing_samples and padded_samples count nominal positions; imputed marks inserted values; affected_by_imputation includes the filter guard; boundary_affected marks initialisation/finite-record context. Flags concern this call, not prior imputation. Explicit fill policies retain counts rather than NA; inspect flags before interpretation.

The settings attribute records reference, exact coefficients, filter, available precision provenance, interval, gaps, padding, discarded samples, rounding and quality conventions.

Validation scope

Default axis counts matched the pinned Python reference exactly for 3,763,659 paired one-second values. ActiLife export agreement depends on precision, startup context and gaps; see the validation guide.

References

Neishabouri et al. (2022). Quantification of acceleration as activity counts in ActiGraph wearable. Scientific Reports 12, 11958. doi:10.1038/s41598-022-16003-x.

Published coefficients: ActiGraph/agcounts, GPL-3.0, commit 3137c9b9a26539ae2d9645d396586fe15faece59. https://github.com/actigraph/agcounts. Numerical coefficients are acknowledged from that source; the R implementation is provided by Metronautica.

Compute Activity Index

Description

Noise-adjusted one-second Activity Index, aggregated by epoch.

Usage

accel_metric_ai(tbl, epoch_s, fs_hz, anchor = "center", ai_noise_var
    = NULL, ai_noise_mode = c("supplied", "window_start",
    "quiet_segments"),
    ai_noise_window_s = 30, ai_quiet_quantile = 0.1, ai_scale =
    c("absolute", "relative"), ai_epoch_summary = c("sum", "mean"))

Arguments

tbl

Acceleration table or parser/clip bundle; see common-data-format.

epoch_s

Positive epoch duration (s); see the pipeline epoch conventions in compute_accel_summaries.

fs_hz

Finite positive sampling frequency (Hz), used for sample windows or time integrals.

anchor

Output timestamp selected from the one-second bin starts: first for start, last for end, or the middle bin start (ceiling of half the bin count) for center. This differs from sample-level anchors of ENMO/MAD and does not change the calculated values.

ai_noise_var

Mean-axis stationary noise variance (g squared), required by default for AI; estimate with compute_ai_noise_var_from_static. Zero disables noise subtraction.

ai_noise_mode

supplied (default) requires ai_noise_var. With NULL variance, window_start or quiet_segments enables estimation; supplied variance takes precedence. The initial window must be stationary; quiet selection does not prove stationarity. Failed estimation errors, without substituting zero.

ai_noise_window_s

Initial noise-window duration (s), for window_start only.

ai_quiet_quantile

quiet_segments selection quantile, strictly between zero and one.

ai_scale

Absolute Activity Index in g (default) or dimensionless noise-relative Activity Index.

ai_epoch_summary

Epoch sum (default) or mean of one-second Activity Index values.

Details

Calculate sample variance per axis within one-second windows, average the three variances, subtract the stationary mean-axis noise variance, truncate negative excess to zero and take the square root. The absolute index is in g. Relative scaling divides excess variance by noise variance before the square root; zero noise variance gives undefined relative values. Aggregate the one-second indices by the selected sum or mean.

Value

A tibble with epoch_id, time and value. Absolute output is in g; relative output is dimensionless. Sum/mean aggregate one-second indices, not acceleration samples. The settings attribute records noise variance/source, estimation settings, scale, aggregation, rate and duration; ai_noise_var_used also records the variance in g squared.

References

Bai et al. (2016), doi:10.1371/journal.pone.0160644.

Compute MIMS-unit

Description

MIMS-unit output using configurable upstream MIMSunit processing.

Usage

accel_metric_mims(tbl, epoch_s, dynamic_range_g, mims_filter_type =
    "butter", mims_cutoffs = c(0.2, 5), mims_use_extrapolation =
    TRUE, mims_use_filtering = TRUE, mims_combination = "sum",
    mims_allow_truncation = TRUE)

Arguments

tbl

Acceleration table or parser/clip bundle; see common-data-format.

epoch_s

Positive epoch duration in seconds, passed as the upstream MIMS epoch setting. MIMSunit controls epoch boundaries, timestamps and treatment of partial epochs; this helper does not impose the common elapsed-sample epoch index.

dynamic_range_g

Configured peak-to-peak axis span (g): 16 means -8 to +8 g. Required by the direct MIMS helper; the summary function accepts NULL only with valid acquisition metadata. Missing range errors; observed values never define it.

mims_filter_type

MIMSunit::custom_mims_unit filter: butter (default), ellip or bessel, as supported upstream; used with mims_cutoffs.

mims_cutoffs

Filter cutoffs in Hz; default c(0.2, 5). Use c(0.2, 10) explicitly for the altered passband.

mims_use_extrapolation

Enable MIMS saturation/extrapolation (TRUE). FALSE skips that step but retains upstream grid interpolation. This concerns acceleration, not behavioural-time extrapolation.

mims_use_filtering

Enable internal MIMS band-pass filtering; FALSE bypasses it and defines a different pipeline.

mims_combination

MIMS axis combination: sum (default) adds axis summaries; vm takes their vector magnitude.

mims_allow_truncation

Allow upstream MIMS to set small summaries to zero; unrelated to native-recording clipping.

Details

Call MIMSunit::custom_mims_unit with triaxial g inputs and configured axis limits. Default 0.2-5 Hz and altered 0.2-10 Hz passbands define different pipelines.

Value

A tibble with time (upstream MIMS epoch labels), epoch_id (sequential row number), and value (the combined MIMS-unit output per epoch). These values are not g or mg. The settings attribute records measurement span/limits, filter and cutoffs, extrapolation, truncation, combination, duration and MIMSunit version.

References

John et al. (2019), An open-source monitor-independent movement summary for accelerometer data processing. doi:10.1123/jmpb.2018-0068.

Compute dynamic body acceleration

Description

Epoch means of overall, vectorial or partial dynamic body acceleration.

Usage

accel_metric_odba(tbl, epoch_s, fs_hz, anchor = "center", output =
    c("ODBA", "VEDBA", "PDBA"), static_dynamic_method =
    c("centered_running_mean", "low_pass_static_filter",
    "high_pass_dynamic_filter"), stroke_window_rule = c("fixed_3s",
    "custom_window_s", "stroke_period_1x", "stroke_period_2x",
    "sensitivity_windows"), running_mean_window_s = 3,
    stroke_period_s = NA_real_, lowpass_cutoff_hz = 0.2,
    highpass_cutoff_hz = 0.2, filter_type = "butterworth",
    filter_order = 4, pdba_axes = c("x", "y"), out_unit = c("mg",
    "g"), edge_handling = "partial_centered_window",
    missing_data_policy = "mean_na_rm")

Arguments

tbl

Acceleration table or parser/clip bundle; see common-data-format.

epoch_s

Positive epoch duration (s); see the pipeline epoch conventions in compute_accel_summaries.

fs_hz

Finite positive sampling frequency (Hz), used for sample windows or time integrals.

anchor

Observed-sample label: first (start), last (end), or ceiling of half the sample count (center). Labels do not change values.

output

ODBA sums absolute dynamic components across all three axes; VEDBA uses their Euclidean norm; PDBA sums the selected absolute components. Each is averaged within the output epoch.

static_dynamic_method

Axis separation method. centered_running_mean subtracts the centred local axis mean; low_pass_static_filter subtracts a low-pass axis estimate; high_pass_dynamic_filter uses high-pass-filtered axes directly.

stroke_window_rule

Window selection for running-mean separation. fixed_3s uses three seconds; custom_window_s uses running_mean_window_s; stroke_period_1x/2x use max(3, stroke_period_s) or max(3, 2*stroke_period_s). sensitivity_windows uses the requested main window and permits a separate sensitivity summary.

running_mean_window_s

Requested centred averaging-window duration in seconds. Used by custom_window_s and the main result of sensitivity_windows; fixed_3s overrides it. Rounded to samples using fs_hz.

stroke_period_s

Positive representative stroke/movement-cycle period in seconds, required for stroke_period_1x/2x. The function does not estimate a movement period.

lowpass_cutoff_hz

Low-pass cutoff in Hz when static_dynamic_method is low_pass_static_filter. Filter each axis and subtract that static estimate before forming the feature.

highpass_cutoff_hz

High-pass cutoff in Hz when static_dynamic_method is high_pass_dynamic_filter. The filtered axes are the dynamic components.

filter_type

Implementation identifier: butterworth is supported for low-/high-pass separation. This is not an automatic choice among filter families.

filter_order

Order passed to signal::butter for the forward/reverse separation filter. The double-pass frequency response differs from a single pass.

pdba_axes

PDBA axes: x, y and/or z; default x/y sums their absolute dynamic components. ODBA/VEDBA are unaffected.

out_unit

Output unit: g, or mg (result multiplied by 1000).

edge_handling

Supported rule partial_centered_window: near signal boundaries, average only the available samples within the centred running window; no external padding is added.

missing_data_policy

Supported rule mean_na_rm: ignore missing observations when calculating local means and epoch means; all-missing estimates remain undefined. This is not gap repair.

Details

Separate static/dynamic axes by the selected implemented method, form ODBA, VEDBA or PDBA, then average within epochs. The centred-window method uses partial available windows at boundaries. A different separation window/filter defines a different pipeline.

Value

Tibble: time (selected epoch label), epoch_id (elapsed-time bin, starting at one), value (selected g or mg unit).

Output settings

The odba_settings attribute records the selected metric, separation method, requested/resolved window duration, cycle-period rule, filter settings, selected axes, output unit and missing-data/edge policies. The direct helper returns one selected metric, not a list of multiple features. The summary function provides separately requested ODBA, VEDBA and PDBA columns.

Description

Calculation definitions and interpretation

Description

Units, normalisation and implemented arithmetic for the public metrology functions.

Details

Vector magnitude is v=\sqrt{a_x^2+a_y^2+a_z^2} in g.

Signed 1-g VM offset bias

Initial one-second mean VM minus 1 g, averaged over elapsed time up to and including five minutes. This is a VM offset relative to gravity, not a complete axis calibration.

Signed VM drift rate

Ordinary least-squares slope against elapsed hours, g/h. Extrapolation beyond the stationary recording requires an explicitly stated model.

Static noise floor

Maximum axis-specific residual SD after linear detrending over the selected stationary window; reporting in mg requires a factor of 1000. The first-five-minute maximum-axis SD is raw, not detrended. Raw sample SD uses denominator n-1; linearly detrended residual SD uses n-2. Static CV is 100 times SD divided by absolute mean, with a near-zero guard.

Allan deviation

For non-overlapping cluster means \bar{x}_j, \sigma_A=\sqrt{\operatorname{mean}[(\bar{x}_{j+1}-\bar{x}_j)^2]/2}. Cluster duration is in seconds and deviation is in g.

Dynamic response and signed VM bias

OLS of test VM on length-matched reference VM. Slope is dimensionless; intercept and mean signed test-minus-reference bias are in g. Scale-factor error is slope minus one; multiply it by 100 for percentage reporting. Absolute VM bias is the absolute value of the stage-mean signed difference, not the mean absolute paired difference.

VM integral non-linearity

100 times the maximum absolute fitted residual divided by \sqrt{3}F, where F is the test-axis peak-to-peak span in g.

Trial-level composite error

100 times the maximum absolute residual from the pooled response fit divided by \sqrt{3}F/2. This denominator differs from stage VM integral non-linearity by a factor of two. The implemented normalising span is not the nonnegative VM output range.

Within-stage epoch-mean VM CV

SD of within-stage epoch mean VM divided by their mean. The retained field repeatability_error_cv is a fraction. It is distinct from trial-to-trial VM repeatability CV, defined as 100 times SD divided by mean of stage-mean VM across repeated trials for the same unit, stage and pipeline.

Maximum-axis Allan minimum

Maximum across axes of their individual minimum Allan deviations over the evaluated averaging times; reporting in micro-g requires a factor of one million. This is distinct from the axis-specific curves.

ENMO

Epoch mean of \max(v-1,0). Negative differences are truncated to zero per sample before averaging.

MAD

Epoch mean of |v-\bar{v}|, with \bar{v} defined within the epoch. ENMO and MAD are multiplied by 1000 for default mg output.

Index-based dynamic reference matching is not timestamp correction. No equivalence margin or universal fit-for-purpose decision is embedded in these functions. Report the reference, tested range, rate, filtering, epoch settings, signal calibration state, error normalisation and relevant timing diagnostics with every application.

Assessment scope

Establish stationary or synchronous excitation conditions separately. Error estimates are not a complete uncertainty budget. WAM (https://github.com/miltheo/wam) supplies cohort aggregation, trial-to-trial repeatability, activation/deadband estimation and inter-device equivalence tests.

Quantify signal and timestamp integrity

Description

Report integrity diagnostics without sorting, repairing or removing samples.

Usage

qc_accel_tbl(x)

Arguments

x

Acceleration table or parser/clip bundle. Requires exactly time (POSIXct), ax_g, ay_g, az_g (numeric g), in that order; metadata precedence follows common-data-format.

Details

The primary-five rules follow Supplementary Table S2 of the research article under submission.

1. Data integrity

Count non-finite timestamps. Count repeated finite timestamps after their first occurrence. Count negative differences between adjacent finite timestamps. Count non-finite acceleration values across X, Y and Z.

Reported output: Four separate counts; total rows and total axis values retained as denominators.

Source: Study-defined availability and ordering checks.

2. Sample timing

Select finite, positive differences between adjacent timestamps. Report their median, interquartile range (IQR) and maximum.

Reported output: Typical spacing, spacing spread and longest spacing (ms).

Source: Study-defined application; IQR is an established measure of spread (NIST/SEMATECH, n.d.).

3. Axis-zero proportion

For each axis, divide the number of exact-zero values by the number of finite values and multiply by 100.

Reported output: Zero values (%) separately for X, Y and Z.

Source: Study-defined descriptive diagnostic.

4. Unusual cross-axis patterns

Count samples with X = Y = Z = 0. Count samples with X = Y = Z and X \neq 0. Flag each pattern separately when it occurs in at least two consecutive eligible samples.

Reported output: Sample count and sequence-present flag for each pattern.

Source: Adapted from NHANES all-zero and equal-axis flags (CDC/NCHS, 2022); the two-sample all-zero minimum is study-defined.

5. Near-limit values

Pool the finite acceleration values from X, Y and Z. Report the percentage whose absolute value is at least 0.98L, where L is the configured positive axis limit.

Reported output: Near-limit values (%); retain L, threshold, numerator and denominator.

Source: NHANES range-limit concept (CDC/NCHS, 2022); 98% and pooling are study-defined. Span terminology follows JCGM (2012, entries 4.4–4.5).

Finite excludes missing values, NaN and infinities. Unavailable quantities are reported as NA. IQR requires at least two positive intervals and uses linearly interpolated quartiles. For symmetric limits, L is half the configured full-scale span. Eligible pattern samples have finite timestamps and XYZ values. Consecutive samples are adjacent recorded rows with strictly increasing timestamps; an ineligible row or non-increasing step breaks a sequence. The equal non-zero value may vary between samples. No gap-duration cutoff is imposed. The intended all-axis NHANES zero condition is used, not its documented X-only implementation error; the original minute-level flag algorithm is not reproduced.

Value

A named list of scalar diagnostics. Counts are sample counts except invalid_axis, near_limit_n and finite_axis_n, which count axis observations. Percentages are on the 0–100 scale.

References

NIST/SEMATECH (n.d.). e-Handbook of Statistical Methods, Section 1.3.5.6: Measures of Scale. https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm.

CDC/NCHS (2022). Data Quality Flag Summary Table for the Physical Activity Monitor (PAM) Data Collected in NHANES 2011–2014 and NNYFS. https://wwwn.cdc.gov/nchs/nhanes/Pam/.

JCGM (2012). International vocabulary of metrology, JCGM 200:2012, entries 4.4–4.5. doi:10.59161/JCGM200-2012.
